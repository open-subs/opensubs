===== OVERVIEW (CHROME) (locale: zh_CN) =====
OpenSubs 是一款免费、开源的字幕工具：它会在你的标签页播放任何内容的同时，使用本地 Whisper 模型对其进行转录。音频永远不会离开你的设备。

使用非常简单：播放视频，点击 OpenSubs 图标，点击 Start。每一部分转录完成后，字幕就会显示在页面上，悬浮层还会显示字幕比语音滞后多少。

功能
• 安装时不请求任何网站访问权限 — 仅在你点击 Start 时，才为当前网站授予权限
• 可在 WebGPU 或 CPU 上运行 — 支持 Tiny、Base 或 Small 模型
• 无需账号、无需注册、无需 API key
• 适用于在页面内直接播放视频或音频的页面：视频网站、讲座录像、录制的演讲
• 自动检测语言，或手动选择
• 可随时关闭的字幕悬浮层
• 导出为 SRT 格式
• 基于 AGPL-3.0 协议开源

OpenSubs 是为那些不想把音频发送到云端的人打造的：重新观看讲座录像的学生、正在学习另一种语言内容的观众、身处嘈杂房间的任何人，以及所有在意隐私的人。

除了浏览器扩展，OpenSubs 还提供 macOS、Windows 和 Linux 的桌面应用，以及 opensubs.app 上的网页版。在你自己设备上运行的一切功能都是免费的。

GitHub: https://github.com/open-subs/opensubs
