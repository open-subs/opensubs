===== OVERVIEW (CHROME) (locale: ko) =====
OpenSubs는 무료 오픈소스 자막 도구입니다: 탭에서 재생되는 모든 콘텐츠를 재생과 동시에 로컬 Whisper 모델을 사용해 자막으로 변환합니다. 오디오는 절대 기기 밖으로 나가지 않습니다.

사용법은 간단합니다: 동영상을 재생하고, OpenSubs 아이콘을 클릭한 뒤, Start를 누르세요. 각 부분이 변환될 때마다 자막이 페이지 위에 나타나며, 오버레이는 자막이 음성보다 얼마나 뒤처져 있는지 보여줍니다.

기능
• 설치 시 웹사이트 접근 권한 없음 — 현재 사이트에 대해서만, 그것도 Start를 눌렀을 때만 부여됨
• WebGPU 또는 CPU에서 실행 — Tiny, Base, Small 모델 지원
• 계정 불필요, 가입 불필요, API 키 불필요
• 페이지 자체에서 동영상이나 오디오를 재생하는 페이지에서 작동: 동영상 사이트, 강의 녹화, 녹음된 강연
• 자동 언어 감지 또는 직접 선택 가능
• 끌 수 있는 자막 오버레이
• SRT로 내보내기
• AGPL-3.0 오픈소스

OpenSubs는 오디오를 클라우드로 보내고 싶지 않은 사람들을 위해 만들어졌습니다: 강의 녹화를 다시 보는 학생, 다른 언어로 된 콘텐츠를 이해하려는 시청자, 시끄러운 방에 있는 사람, 그리고 개인정보를 중요하게 생각하는 모든 사람.

확장 프로그램 외에도, OpenSubs는 macOS, Windows, Linux용 데스크톱 앱과 opensubs.app의 웹 앱으로도 제공됩니다. 자신의 기기에서 실행되는 모든 기능은 무료입니다.

GitHub: https://github.com/open-subs/opensubs
