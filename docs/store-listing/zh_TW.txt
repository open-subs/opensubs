===== OVERVIEW (CHROME) (locale: zh_TW) =====
OpenSubs 是一款免費、開源的字幕工具：它會在你分頁播放任何內容的同時，使用本地 Whisper 模型進行轉錄。音訊永遠不會離開你的裝置。

使用方式很簡單：播放影片，點擊 OpenSubs 圖示，按下 Start。每個部分轉錄完成後，字幕就會顯示在頁面上，浮動視窗還會顯示字幕比語音落後多少。

功能
• 安裝時不會要求任何網站存取權限 — 只有在你按下 Start 時，才會為目前網站授予權限
• 可在 WebGPU 或 CPU 上執行 — 支援 Tiny、Base 或 Small 模型
• 不需帳號、不需註冊、不需 API key
• 適用於直接在頁面中播放影片或音訊的頁面：影片網站、課程錄影、錄製的演講
• 自動偵測語言，或自行選擇
• 可隨時關閉的字幕浮動視窗
• 匯出為 SRT 格式
• 採用 AGPL-3.0 授權開源

OpenSubs 是為那些不想把音訊傳送到雲端的人打造的：重新觀看課程錄影的學生、正在理解其他語言內容的觀眾、身處吵雜房間的任何人，以及所有重視隱私的人。

除了瀏覽器擴充功能，OpenSubs 也提供 macOS、Windows 和 Linux 的桌面應用程式，以及 opensubs.app 上的網頁版。在你自己裝置上執行的所有功能皆為免費。

GitHub: https://github.com/open-subs/opensubs
