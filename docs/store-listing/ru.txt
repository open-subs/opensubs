===== OVERVIEW (CHROME) (locale: ru) =====
OpenSubs — бесплатный инструмент для субтитров с открытым исходным кодом: он транскрибирует всё, что воспроизводится в вашей вкладке, по мере воспроизведения, используя локальную модель Whisper. Аудио никогда не покидает ваше устройство.

Просто в использовании: запустите видео, нажмите на значок OpenSubs, нажмите Start. Субтитры появляются на странице по мере транскрибирования каждой части, а оверлей показывает, насколько они отстают от речи.

Возможности
• Нет доступа к сайтам при установке — доступ предоставляется только для текущего сайта и только когда вы нажимаете Start
• Работает на WebGPU или CPU — модели Tiny, Base или Small
• Без аккаунта, без регистрации, без API-ключа
• Работает на страницах, где видео или аудио воспроизводится прямо на странице: видеосайты, записи лекций, записанные выступления
• Автоматическое определение языка или выбор вручную
• Оверлей субтитров можно отключить
• Экспорт в SRT
• Открытый исходный код по лицензии AGPL-3.0

OpenSubs создан для тех, кто предпочитает не отправлять аудио в облако: студентов, пересматривающих записи лекций, зрителей, разбирающих контент на другом языке, всех, кто находится в шумной комнате, и всех, кому важна приватность.

Помимо расширения, OpenSubs также доступен как настольное приложение для macOS, Windows и Linux, а также как веб-приложение на opensubs.app. Всё, что работает на вашем собственном устройстве, бесплатно.

GitHub: https://github.com/open-subs/opensubs
